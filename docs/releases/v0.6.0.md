# v0.6.0 — Five original landing styles, ready to choose and use

OPC Harness now includes sixteen complete frontend templates and sixteen compatible recipes. Choose an actual interactive preview, apply your brand, and generate the same design for Codex and Claude Code.

## New templates

| Template | Style | Working interaction |
| --- | --- | --- |
| `petal` / Petal | Soft pink native-tool landing | Editable brief, three local writing modes and draft handoff |
| `gauge` / Gauge | Warm, data-led product page | Quick-start form, release checklist and computed readiness chart |
| `scribble` / Littlebrief | Friendly white form page | Original vector doodles, live preview and three-question draft handoff |
| `letterline` / Letterline | Minimal editorial landing | Oversized type, expandable project notes and sample handoff |
| `nocturne` / Nocturne | Premium dark product page | Automatic three-stage walkthrough, manual steps and motion preferences |

All five use original brands, copy, logos, vector assets and product demonstrations. Reference links are catalogue metadata. Generated pages do not bundle the reference sites' source, logos, screenshots or videos.

## Install once

```sh
npx --yes opc-harness@0.6.0 setup --global --host both
```

Setup preserves existing personal defaults and unrelated instructions. Start a new agent session, describe your website, and name a template when you have a preference.

```text
Build a website for a reading notebook using the petal template.
Brand: Small Hours. Preserve the layout and interactions, and replace the sample content.
```

Compare the real previews:

```sh
npx --yes opc-harness@0.6.0 gallery
```

Or generate a project directly:

```sh
npx --yes opc-harness@0.6.0 create --dir ./small-hours --name small-hours \
  --template petal --stack cloudflare --payment none --brand 'Small Hours' --host both
```

## Improvements

- Gallery previews and generated projects share the same renderer and assets, including locally bundled Inter with its license.
- Search finds templates by reference number and reference website name.
- Brand overrides apply to the selected example. Other templates keep their own defaults; footer wordmarks remain intact.
- The local studio copies a command for the exact running runtime, avoiding incompatible package versions.
- New templates carry their brand, typography and palette into the brief workspace and checkout pages.
- A single-use, project-scoped handoff transfers draft content without replacing saved work until the visitor explicitly saves it.
- Design locks protect font bytes in addition to page structure, styles and behavior.
- Workspace errors display their message instead of recursively formatting the same error.

## Compatibility and verification

The CLI entry points, one-command setup, both agent integrations, Cloudflare / Vercel static / portable static stacks, and existing demo / Stripe test payment boundaries remain available. The new templates default to free exports; paid Cloudflare configurations continue through the existing server-verified workspace flow.

Strict TypeScript, syntax and release-text checks pass. The regression suite passes 158 tests. Package smoke testing generates all sixteen templates and recipes, installs both hosts in an isolated home, survives npx-cache removal, and runs a real Wrangler packaging dry run without requiring TypeScript at runtime. Chrome checks cover all five templates at 1440px and 390px, live branding, draft transfer, checklist updates and synchronized walkthrough states.

The sample checklist is not business analytics; local writing modes do not call an AI service; editorial notes do not send newsletters; and the animated walkthrough does not record video. New external payment transactions and forced reduced-motion browser emulation were not rerun for this frontend release.
