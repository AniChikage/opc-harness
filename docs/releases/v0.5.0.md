# v0.5.0 — Modular delivery, strict TypeScript and a separate web workspace

OPC Harness now lets Codex and Claude Code choose a complete website, combine compatible modules and follow a checked path from design to preview delivery.

## Highlights

- Eleven complete frontend templates and eleven compatible recipes, with exact local previews and related reference websites.
- Independent Cloudflare, Vercel static and portable static stacks; incompatible payment/stack combinations fail explicitly.
- Configurable brand, content, price and project JSON, plus design locks that detect layout and behavior drift.
- Free preview, demo or Stripe test checkout, signed callbacks, idempotent fulfillment and protected Markdown delivery in the Cloudflare recipe.
- Strict TypeScript for the CLI, browser modules, Worker, tests and release tooling. npm consumers receive compiled JavaScript and do not need a compiler.
- Preserved standalone agent setup for both hosts, existing runtime CLI paths, personal defaults, backups and npx-cache independence.

## Repository layout

The root remains the harness package: CLI, project templates, skills, payment logic and deployment adapters.

The private `web/` workspace owns the product homepage, six-second workflow animation, Studio source, website assets, tests and static export. It has independent development/build/test commands and a separate CI job. The harness packages only the generated Studio assets required for offline template selection; it excludes the marketing homepage, animation and font files.

```sh
npm ci
npm run build
node bin/opc.mjs setup --global --host both
node bin/opc.mjs gallery

# Optional website development:
npm --prefix web run dev
```

## Release assets and npm availability

`opc-harness-0.5.0.tgz` is the tested, compiled harness package. `opc-harness-web-0.5.0.zip` is the separate static website; deploy its extracted contents at an origin root.

Install the harness from this GitHub Release in one command:

```sh
npx --yes --package=https://github.com/AniChikage/opc-harness/releases/download/v0.5.0/opc-harness-0.5.0.tgz opc-harness setup --global --host both
```

This GitHub Release does not publish to the npm registry. npm `latest` was independently checked as 0.3.0 on November 10, 2026; use the attached v0.5.0 package or build this source until the npm version is published.

## Validation

- 131 harness tests and 13 web tests passed after the directory split; both workspaces pass strict type checking.
- The actual tarball installs both host entries in an isolated home, creates every template and recipe, survives npx cache removal and makes no changes on repeated setup.
- A copied project bootstraps pinned Wrangler without TypeScript and completes a real local packaging dry run.
- Browser checks cover all eleven templates on desktop/mobile, Studio selection/live branding/config downloads, seven homepage viewport sizes and complete automatic animation cycles.
- Local SQLite/D1 checks cover fulfillment, signature rejection, retries, access control and demo checkout-to-download. A browser-downloaded Markdown file was read and checked against its current input.

External Stripe transactions, new remote Cloudflare/Vercel deployments and fresh model sessions were not rerun for this release. Live payments, subscriptions, merchant onboarding, shared user accounts and native Windows host acceptance remain outside the verified scope.
