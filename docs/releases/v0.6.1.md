# v0.6.1 — Open complete previews from template thumbnails

Clicking a template thumbnail in the Studio now opens its complete interactive preview. Thumbnail iframes no longer intercept clicks intended for the preview button. The full-size preview remains interactive.

This patch includes all five landing styles introduced in [v0.6.0](v0.6.0.md): Petal, Gauge, Littlebrief, Letterline and Nocturne. The catalogue contains sixteen templates and sixteen recipes.

## Install once

```sh
npx --yes opc-harness@0.6.1 setup --global --host both
```

Compare the actual templates:

```sh
npx --yes opc-harness@0.6.1 gallery
```

Generate a project:

```sh
npx --yes opc-harness@0.6.1 create --dir ./small-hours --name small-hours \
  --template petal --stack cloudflare --payment none --brand 'Small Hours' --host both
```

The public website consumes this exact npm version and displays the five new styles first. Preview selection, brand customization and copied creation commands use the same template renderer as generated projects.

## Compatibility

Both agent integrations, one-command setup, existing project configuration, design locks, stacks and payment modes retain their existing behavior. This patch changes only thumbnail pointer handling and the current installation examples.
